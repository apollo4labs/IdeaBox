# Desktop & OS Topics

Collection of ideas for desktop applications, system utilities, and OS-integrated experiences.

## Current Ideas

### Living City Live Wallpaper
A dynamic, context-aware desktop wallpaper: a living medieval city (in the "Arc of Icarus" low-poly isometric / sci-fi style) that builds, farms, and evolves over the day — driven by real local time, weather, and seasons, then "burns down" and rebuilds fresh each evening.

**Status:** Concept
**Folder:** `topics/desktop/living-city-wallpaper/`
